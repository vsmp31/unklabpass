# ScanVec 🎯

Advanced AI Vector Intelligence & Scanning Dashboard.

## Features
- 📊 **Real-time Analytics**: Monitor vector processing and system performance.
- 🚀 **YOLO Vision**: Integrated object detection using YOLOv8 with support for file uploads and camera input.
- 🔍 **Vector Search**: Search through embeddings with high precision.
- 🛠 **Customizable Settings**: Fine-tune embedding models and indexing.
- 🎨 **Premium UI**: Modern dark-mode interface with glassmorphism effects.

## Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the Application
```bash
flask run
```

## Project Structure
- `app.py`: Main application entry point.
- `requirements.txt`: Python package dependencies.
